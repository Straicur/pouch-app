# Dokumentacja projektu

Ten katalog jest kanonicznym punktem wejścia do wersjonowanej dokumentacji projektu `pouch-app`. Plik `CLAUDE.md` kieruje agentów do tego indeksu.

## Jak korzystać z dokumentacji

- Przed rozpoczęciem pracy przeczytaj zasady projektu i dokumenty właściwe dla zmienianego obszaru.
- Nie wczytuj wszystkich dokumentów bez potrzeby. Korzystaj z poniższego routingu.
- Niewersjonowany plik nie jest źródłem prawdy tylko dlatego, że znajduje się lokalnie w repozytorium.
